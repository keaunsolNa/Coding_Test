3. **풀이 접근법**: 이 쿼리는 창함수(윈도우 함수)를 사용하여 데이터를 처리합니다. 특히, `ROW_NUMBER()` 함수를 사용하여 각 사원의 최근 리뷰를 식별하고, `LAG()` 함수를 사용하여 이전 리뷰의 평점과 현재 리뷰의 평점을 비교하여 개선 점수를 계산합니다. 또한, 조인과 그룹화를 사용하여 사원 정보를 결합하고, 개선 점수를 집계합니다.
