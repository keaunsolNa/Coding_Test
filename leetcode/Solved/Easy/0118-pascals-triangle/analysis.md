```java
for (int i = 2; i <= numRows; i++) {
    List<Integer> row = new ArrayList<>();
    row.add(1);
    List<Integer> prevRow = list.get(i - 1);
    for (int j = 1; j < i - 1; j++) {
        row.add(prevRow.get(j - 1) + prevRow.get(j));
    }
    row.add(1);
    list.add(row);
}
```

이러한 최적화를 통해 코드의 효율성을 향상시킬 수 있습니다.
