## Code Review

**1. 시간 복잡도**  
- **O(N)** : `details` 배열의 길이를 N이라고 할 때, 각 문자열을 한 번씩 순회하면서 `substring`·`parseInt` 를 수행합니다. 문자열 길이는 고정(최소 8자 이상)이라서 각 원소당 연산은 O(1)이며 전체는 O(N)입니다.

**2. 공간 복잡도**  
- **O(1)** : 추가적인 동적 메모리를 거의 사용하지 않습니다. `cnt`와 `age` 두 개의 정수 변수만 사용하고, `substring` 으로 만든 임시 문자열은 JVM 내부에서 재사용되므로 입력 크기에 비례하는 메모리는 필요하지 않습니다.

**3. 풀이 접근법**  
- 문자열의 뒤에서 두 번째와 세 번째 자리(‘YY’ 형태)만 추출해 정수로 변환하고, 60 초과인 경우 카운트합니다.  
- 즉, **문자열 슬라이싱 + 정수 파싱**이라는 단순한 문자열 처리 방식이며, 별도의 자료구조나 복잡한 알고리즘을 사용하지 않은 **그리디** 방식이라고 볼 수 있습니다.

**4. 잘된 점**  
- 코드가 매우 간결하고 가독성이 좋습니다.  
- `for‑each` 문을 사용해 배열을 직관적으로 순회하고, `Integer.parseInt` 로 연령을 바로 정수화해 비교 로직을 명확히 했습니다.  
- 불필요한 조건 검사나 중간 리스트 생성 없이 바로 카운트만 증가시켜 메모리 사용을 최소화했습니다.

**5. 개선 사항**  
1. **연령 파싱 방식 최적화**  
   - `substring` 후 `parseInt` 를 호출하면 임시 문자열 객체가 생성됩니다. 연령이 항상 두 자리(`00`~`99`)라는 점을 이용해 문자 하나씩 빼서 직접 정수로 변환하면 객체 생성을 없앨 수 있습니다. 예시:  
     ```java
     int age = (str.charAt(str.length() - 4) - '0') * 10
             + (str.charAt(str.length() - 3) - '0');
     ```
   - 이 경우 시간 복잡도는 동일하지만, 메모리 할당 비용이 감소합니다.

2. **경계 조건 명시**  
   - 문제에서 “60세 이상”인지 “초과”인지 명확히 확인하고 조건을 `>= 60` 혹은 `> 60` 로 맞춰야 합니다. 현재 `> 60` 로 구현돼 있으니 문제 요구사항과 일치하는지 검증이 필요합니다.

3. **입력 검증** (선택 사항)  
   - 문자열 길이가 충분히 긴지, 연령 부분이 숫자인지 확인하는 방어 코드를 넣으면 예외 상황에 대한 안정성이 높아집니다. 다만 LeetCode에서는 보통 입력이 정상이라고 가정합니다.

4. **메서드 시그니처**  
   - `public int countSeniors(String[] details)` 은 문제 요구와 일치하지만, Java 8 이상이라면 `Stream` 을 활용한 한 줄 구현도 가능합니다. 가독성은 떨어질 수 있지만, 함수형 스타일을 연습하고 싶다면 참고하세요.  
     ```java
     return (int) Arrays.stream(details)
                        .filter(s -> Integer.parseInt(s.substring(s.length()-4, s.length()-2)) > 60)
                        .count();
     ```

전반적으로 코드가 깔끔하고 요구사항을 정확히 만족합니다. 위의 작은 최적화를 적용하면 메모리 할당을 더 줄일 수 있지만, 현재 구현도 충분히 효율적이며 **Easy** 난이도에 적합합니다.
