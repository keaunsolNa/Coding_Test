예를 들어, 다음 코드는 각 열을 비교하여 정렬된 순서가 아니면 삭제해야 하는 열의 개수를 계산하는 알고리즘을 사용합니다.

```java
class Solution {
    public int minDeletionSize(String[] strs) {
        int m = strs.length;
        int n = strs[0].length();
        int ans = 0;
        
        for (int j = 0; j < n; j++) {
            for (int i = 1; i < m; i++) {
                if (strs[i].charAt(j) < strs[i-1].charAt(j)) {
                    ans++;
                    break;
                }
            }
        }
        
        return ans;
    }
}
```
