## Code Review

코드 리뷰입니다.

1. **시간 복잡도**: O(n*m)입니다. 여기서 n은 문자열의 개수(rowCount), m은 문자열의 길이(columnCount)입니다. 코드는 각 문자열의 각 문자를 비교하기 때문에 이 시간 복잡도가 발생합니다.

2. **공간 복잡도**: O(1)입니다. 코드는 입력 문자열 배열 외에 추가적인 공간을 사용하지 않습니다. 따라서 공간 복잡도는 상수입니다.

3. **풀이 접근법**: 이 문제는 각 열의 문자를 비교하여 정렬된 순서가 아니면 해당 열을 삭제하는 접근법을 사용합니다. 이는 간단한 반복문을 사용하여 구현할 수 있습니다. 코드에서는 두 개의 중첩된 반복문을 사용하여 각 열의 문자를 비교합니다.

4. **잘된 점**: 코드는 간결하고 쉽게 이해할 수 있습니다. 변수 이름도 의미가 명확하여 코드의 가독성이 좋습니다. 또한, 시간 복잡도와 공간 복잡도도 효율적입니다.

5. **개선 사항**: 코드는 이미 효율적이지만, 변수 이름을 더 자세하게 지정하거나 주석을 추가하여 코드의 의미를 더 명확하게 할 수 있습니다. 예를 들어, `columnIndex`와 `rowIndex` 변수 이름을 더 자세하게 지정하거나, `deletionCount` 변수의 의미를 주석으로 설명할 수 있습니다. 또한, 입력 문자열 배열이 null인지 체크하는 예외 처리를 추가할 수 있습니다.
