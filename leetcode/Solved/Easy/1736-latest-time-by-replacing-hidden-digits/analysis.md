## Code Review

**1. 시간 복잡도**  
- **O(1)**  
  입력 문자열의 길이는 항상 고정(5)이며, `split`, `charAt`, 문자열 결합 등 수행되는 연산이 상수 개수이므로 전체 실행 시간은 입력 크기에 영향을 받지 않는다.

**2. 공간 복잡도**  
- **O(1)**  
  추가로 생성되는 문자열은 `hour`, `min`, 그리고 최종 반환 문자열 정도뿐이며, 크기가 고정돼 있다. 따라서 사용되는 메모리도 입력 크기에 비례하지 않는다.

**3. 풀이 접근법**  
- **그리디** 방식으로 각 자리의 ‘?’ 를 가능한 가장 큰 숫자로 교체한다.  
  - 시(hour) 첫 번째 자리: 가능한 최대값은 2이며, 두 번째 자리는 첫 자리가 2일 때는 3, 그 외에는 9 로 정한다.  
  - 분(minute) 첫 번째 자리: 최대 5, 두 번째 자리: 최대 9 로 채운다.  
- 문자열을 직접 조작하면서 조건을 체크해 올바른 24시간 형식을 만든다.

**4. 잘된 점**  
- 문제의 핵심인 “가능한 가장 큰 유효 시간”을 정확히 구현했다.  
- `split(":")` 로 시와 분을 분리해 가독성을 어느 정도 확보했다.  
- `chk` 플래그를 사용해 첫 번째 시 자리에서 ‘2’ 로 고정했을 때 두 번째 자리 제한을 적용한 점이 논리 흐름을 명확히 한다.

**5. 개선 사항**  

| 항목 | 현 코드 | 개선 제안 |
|------|----------|-----------|
| **가독성** | 문자열을 직접 `+` 연산으로 이어 붙이고, `charAt` 결과를 다시 문자열로 변환하는 부분이 복잡함 | `StringBuilder` 혹은 `char[]` 배열을 사용해 각 자리별로 직접 할당하면 더 직관적이며, `hour.charAt(0) == '?'` 와 같은 조건을 `if-else` 로 명확히 구분할 수 있다. |
| **불필요한 `split`** | `time.split(":")` 를 두 번 호출 (시와 분 각각) | 한 번만 호출하고 결과를 변수에 저장하거나, `time.charAt` 로 직접 접근해 `:` 위치를 기준으로 처리하면 메모리 할당을 줄일 수 있다. |
| **플래그 사용** | `chk` 플래그는 첫 번째 자리를 ‘2’ 로 고정했는지 여부만 저장한다. | 첫 번째 자리 결정 후 바로 두 번째 자리 조건을 판단하도록 로직을 재구성하면 플래그가 필요 없어진다. 예: `if (hour.charAt(0) == '2') hour = "2" + (hour.charAt(1) == '?' ? '3' : hour.charAt(1));` |
| **문자와 문자열 혼용** | `hour = hour.charAt(0) + (hour.charAt(0) == '2' ? "3" : "9");` 와 같이 `char + String` 연산이 암묵적으로 정수 연산으로 변환될 위험이 있음 | `String.valueOf(hour.charAt(0)) + (hour.charAt(0) == '2' ? "3" : "9")` 혹은 `char[]` 로 직접 할당해 타입 혼동을 방지한다. |
| **예외 상황** | 입력이 항상 `"??:??"` 형태라고 가정하지만, 실제 LeetCode에서는 입력 검증이 필요 없으므로 큰 문제는 아니지만, `split` 결과가 예상과 다르면 `ArrayIndexOutOfBoundsException` 가능 | `time.charAt` 로 직접 접근하면 이런 위험을 원천 차단한다. |
| **테스트 커버리지** | 코드가 특정 케이스(예: `"2?:?0"`) 에서 올바르게 동작하는지 명시적 검증이 부족 | 주요 경우(첫 자리 ‘2’, 두 번째 자리 ‘?’, 분 첫 자리 ‘?’, 등) 를 주석이나 별도 테스트 메서드로 정리하면 유지보수가 쉬워진다. |

**요약**  
현재 구현은 문제 요구사항을 만족하는 간결한 그리디 풀이이며, 시간·공간 복잡도 모두 O(1)이다. 다만 문자열 조작 방식이 다소 복잡하고 `split`·플래그 사용이 불필요하게 보이므로, `char[]` 혹은 `StringBuilder` 로 각 자리별 직접 할당하는 형태로 리팩터링하면 가독성과 안전성이 크게 향상된다.
