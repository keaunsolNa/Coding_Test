## Code Review

**1. 시간 복잡도**  
- **O(1)**  
  문자열 길이는 항상 고정(5자리, “hh:mm”)이며, `split`, `charAt`, `substring` 등은 모두 상수 시간에 수행됩니다. 따라서 입력 크기에 관계없이 실행 시간은 일정합니다.

**2. 공간 복잡도**  
- **O(1)**  
  추가로 생성되는 문자열은 `hour`, `min`, 그리고 최종 반환 문자열 정도뿐이며, 모두 입력 길이와 동일한 상수 크기입니다. 힙에 할당되는 메모리도 입력 크기에 비례하지 않으므로 상수 공간 복잡도를 가집니다.

**3. 풀이 접근법**  
- 문자열을 `:` 로 분리한 뒤, 각 자리(`?`)를 가능한 가장 큰 숫자로 교체해 **최대 시간**을 만든다.  
- 시(hour)와 분(minute) 각각에 대해 자리별 제약(00~23, 00~59)을 고려해 조건문으로 직접 구현하였다.  
- 기본적인 **그리디**(greedy) 전략으로, 각 자리에서 가능한 가장 큰 값을 선택하는 방식이다.

**4. 잘된 점**  
- 문제의 핵심인 “가능한 가장 큰 시간”을 정확히 구현했으며, 불필요한 반복이나 복잡한 로직 없이 한 번의 조건 검사만으로 해결했다.  
- `split`을 이용해 시와 분을 명확히 구분하고, `substring`을 활용해 자리 교체를 간결하게 표현했다.  
- 전체 로직이 짧고 가독성이 좋으며, `if` 문만으로 모든 경우를 처리해 구현이 직관적이다.

**5. 개선 사항**  
1. **`split` 호출 중복 제거**  
   ```java
   String[] parts = s.split(":");
   String hour = parts[0];
   String min  = parts[1];
   ```
   현재는 `s.split(":")`를 두 번 호출하고 있어 불필요한 문자열 배열 생성이 발생한다. 한 번만 호출하도록 수정하면 약간의 메모리/시간 절감이 가능하다.

2. **`substring` 사용 최소화**  
   `substring`은 새로운 문자열 객체를 만든다. 자리 교체를 `StringBuilder` 혹은 문자 배열(`char[]`)로 하면 객체 생성 횟수를 줄일 수 있다. 예시:
   ```java
   char[] h = hour.toCharArray();
   if (h[0] == '?') h[0] = (h[1] == '?' || h[1] <= '3') ? '2' : '1';
   if (h[1] == '?') h[1] = (h[0] == '2') ? '3' : '9';
   hour = new String(h);
   ```
   이렇게 하면 `substring`에 비해 메모리 할당이 적어진다.

3. **조건 로직 간소화**  
   현재 시(hour) 부분은 세 개의 `if` 로 복잡하게 얽혀 있다. 시의 첫 번째 자리를 먼저 판단하고, 두 번째 자리를 그 결과에 따라 결정하면 더 명확해진다.
   ```java
   if (hour.charAt(0) == '?') {
       hour = (hour.charAt(1) == '?' || hour.charAt(1) <= '3') ? "2" + hour.charAt(1) : "1" + hour.charAt(1);
   }
   if (hour.charAt(1) == '?') {
       hour = hour.charAt(0) + (hour.charAt(0) == '2' ? "3" : "9");
   }
   ```
   이렇게 하면 “11시대에 9를 넣는다” 같은 특수 케이스를 별도 처리할 필요가 없어진다.

4. **테스트 커버리지**  
   현재 코드가 모든 가능한 입력(`??:??`, `2?:?5`, `0?:?0` 등)을 올바르게 처리하는지 확인하기 위해 경계값 테스트를 추가하는 것이 좋다. 특히 `hour.charAt(0) == '1' && !(hour.charAt(1) == '0' || hour.charAt(1) == '1')` 와 같은 로직이 `12`, `13` 등 24시 범위를 초과하는 경우를 정확히 교정하는지 검증이 필요하다.

5. **가독성 향상**  
   각 자리별 의미를 주석으로 명시하거나, `replaceHour`, `replaceMinute` 같은 작은 헬퍼 메서드로 분리하면 코드 가독성이 더욱 높아진다.
