## Code Review

**코드 리뷰**

1. **시간 복잡도**  
   - **O(N)** : `nums` 배열을 한 번 순회하면서 현재 위치를 누적하고, 0이 되는지를 검사합니다. N은 입력 배열의 길이이며, 반복문 안의 연산은 모두 O(1)입니다.

2. **공간 복잡도**  
   - **O(1)** : 추가적인 배열이나 리스트를 사용하지 않고, `position`과 `cnt` 두 개의 정수 변수만 사용합니다. 입력 배열 외에 별도의 동적 메모리를 할당하지 않으므로 상수 공간 복잡도를 가집니다.

3. **풀이 접근법**  
   - **누적 합 (Prefix Sum) 시뮬레이션** : 개미가 한 번에 이동하는 거리 `nums[i]` 를 순차적으로 더해 현재 위치를 추적합니다. 누적 합이 0이 되는 순간(즉, 경계점에 도달)마다 카운트를 증가시킵니다. 별도의 자료구조 없이 단순한 시뮬레이션으로 문제를 해결합니다.

4. **잘된 점**  
   - **간결하고 직관적인 구현** : 변수명(`position`, `cnt`)이 의미를 잘 전달하고, 로직이 한 눈에 들어옵니다.  
   - **불필요한 연산이 없음** : 매 반복마다 바로 누적값을 업데이트하고 검사하므로 불필요한 중간 단계가 없습니다.  
   - **상수 공간 사용** : 문제 요구사항에 맞게 메모리를 최소화했습니다.

5. **개선 사항**

     - 클래스가 `Solution`이라면 `public` 메서드만 필요하므로 현재 선언은 적절합니다.  
   - **입력 검증**  
     - 문제에서 `nums`가 비어 있지 않다고 가정하지만, 방어적인 코드를 원한다면 `if (nums == null || nums.length == 0) return 0;` 과 같은 체크를 추가할 수 있습니다.  
   - **주석 추가**  
     - 간단한 주석을 달아 “현재 위치를 누적하고 0이면 카운트 증가”와 같은 설명을 넣으면 유지보수 시 도움이 됩니다.  
   - **가능한 대안**
