## Code Review

로마 숫자를 정수로 변환하는 문제의 코드 리뷰입니다.

1. **시간 복잡도**: O(n) - 입력 문자열의 길이(n)에 비례하는 시간이 소요됩니다. 이는 문자열을 한 번만 순회하기 때문입니다.
2. **공간 복잡도**: O(n) - 입력 문자열을 문자 배열로 변환하기 때문에 공간 복잡도가 입력 문자열의 길이(n)에 비례합니다. 그러나 실제로는 문자열을 배열로 변환하는 것 외에 추가적인 공간을 많이 사용하지 않으므로, praktisch하게는 O(1)이라고 볼 수 있습니다.
3. **풀이 접근법**: 이 문제는 단순한 문자열 순회와 로마 숫자의 규칙을 적용하여 정수로 변환하는 알고리즘을 사용합니다. 로마 숫자의 규칙을 잘 이해하고, 이전 문자와 현재 문자를 비교하여 정수를 계산하는 방식입니다.
4. **잘된 점**: 코드는 로마 숫자를 정수로 변환하는 논리를 명확하게 구현했습니다. 또한, `convertCharToInt` 메서드를 분리하여 코드의 가독성을 높였습니다.
5. **개선 사항**: 코드는 이미 bastante 최적화되어 있습니다. 그러나, 입력 문자열의 유효성을 검사하는 코드를 추가하여 예외 상황을 처리할 수 있습니다. 또한, `switch` 문 대신에 HashMap을 사용하여 로마 숫자와 정수의 매핑을 구현할 수 있습니다. 그러나, 이 경우에는 코드의 가독성이 떨어질 수 있으므로, 현재의 구현이 더 좋을 수 있습니다.
