## Code Review

로마 숫자를 정수로 변환하는 문제의 코드 리뷰입니다.

1. **시간 복잡도**: O(n) - 입력 문자열의 길이(n)에 비례하여 단 한번의 루프를 돌기 때문에 선형 시간 복잡도를 가집니다. 각 문자를 처리하는 데 상수 시간이 소요되므로 전체 시간 복잡도는 입력 크기에 직접적으로 비례합니다.

2. **공간 복잡도**: O(1) - 입력 문자열을 배열로 변환하고 몇 개의 변수를 사용하므로, 공간 사용량이 입력 크기에 비례하지 않습니다. 즉, 상수 공간 복잡도를 가집니다. 다만 입력 문자열을 배열로 변환하는 과정에서 추가적인 공간이 사용되기는 하지만, 이는 입력 크기와 직접적인 비례 관계가 아니므로 상수 공간 복잡도로 간주합니다.

3. **풀이 접근법**: 이 문제는 로마 숫자의 특성을 이용한 단순한 문자열 처리 알고리즘을 사용합니다. 각 로마 숫자를 정수로 변환하고, 현재 숫자가 이전 숫자보다 크거나 같으면 더하고, 그렇지 않으면 뺀다는 규칙을 적용하여 총합을 계산합니다. 이는 그리디 알고리즘의 특성을 일부 반영합니다.

4. **잘된 점**: 코드는 비교적 간결하고, 로마 숫자를 정수로 변환하는 부분을 별도의 메서드로 분리하여 코드의 가독성과 재사용성을 높였습니다. 또한, 문제를 단순하게 해결하는 접근법을 사용하여 코드의 복잡도를 낮추었습니다.

5. **개선 사항**: 현재 코드는 로마 숫자의 특성을 잘 이용하고 있지만, 일부 로직이 직관적이지 않을 수 있습니다. 예를 들어, `if (now >= prev) total -= now; else total += (now - prev);` 부분은 로마 숫자의 규칙을 적용하는 데 사용되지만, 처음 보는 사람에게는 이해하기 어렵습니다. 이를 더 명확하게 하거나, 주석을 추가하여 로직을 설명하는 것이 좋을 것입니다. 또한, `total -= now;` 대신에 `total += now;`를 사용하고, 이전 숫자가 현재 숫자보다 작을 때에만 추가적인 처리를 하는 방식으로 로직을 개선할 수 있습니다. 예를 들어, `if (now > prev) total += now - 2 * prev; else total += now;`와 같이 이전에 더해진 숫자를 다시 빼고 현재 숫자를 더하는 방식으로 코드를 개선할 수 있습니다.
