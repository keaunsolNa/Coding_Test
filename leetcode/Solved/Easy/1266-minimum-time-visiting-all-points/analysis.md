## Code Review

**코드 리뷰 (한국어)**  

---

### 1. 시간 복잡도  
- **O(N)** (N = `points.length`)  
- 한 번의 `for` 루프에서 인접한 두 점 사이의 거리만 계산하므로, 입력 크기에 비례해서 한 번씩만 연산한다.  

### 2. 공간 복잡도  
- **O(1)**  
- 추가적인 배열이나 리스트를 사용하지 않고, 정수 변수 `ans`, `h`, `v`만 사용한다. 입력 배열 `points`는 그대로 참조한다.  

### 3. 풀이 접근법  
- **그리디(직접 계산) 방식**  
  - 두 점 사이를 이동할 때 대각선 이동이 가능하므로, 한 단계에 가로·세로 중 큰 값만큼 이동하면 된다.  
  - 따라서 `max(|dx|, |dy|)`가 두 점 사이를 이동하는 최소 시간이며, 이를 모든 인접 쌍에 대해 누적한다.  

### 4. 잘된 점  
- **간결하고 명확함** : 핵심 로직이 5줄 안에 구현돼 가독성이 높다.  
- **수학적 사실 활용** : 대각선 이동을 고려한 `Math.max` 사용이 정확하고 직관적이다.  
- **불필요한 객체 생성 없음** : 기본형 변수만 사용해 메모리 오버헤드가 최소다.  

### 5. 개선 사항  
| 항목 | 내용 | 비고 |
|------|------|------|
| **입력 검증** | `points`가 `null`이거나 길이가 0인 경우를 방어적으로 처리하면 더 견고해진다. | `if (points == null || points.length == 0) return 0;` |
| **변수명** | `h`, `v` 보다는 `dx`, `dy` 혹은 `deltaX`, `deltaY`가 의미를 더 명확히 전달한다. | 가독성 향상 |
| **루프 시작 인덱스** | 현재는 `i = 1`부터 시작해 `i-1`을 참조한다. 이는 자연스럽지만, `for (int i = 0; i < points.length - 1; ++i)` 형태로 바꾸면 `i`와 `i+1`을 사용해 인덱스 경계 검사가 더 명확해진다. | 선택 사항 |
| **주석** | 핵심 아이디어(대각선 이동 시 `max`가 최소 시간임)를 간단히 주석으로 남기면 코드 이해가 빠른 팀원에게 도움이 된다. | 가독성 |
