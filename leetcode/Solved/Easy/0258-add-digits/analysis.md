## Code Review

코드 리뷰입니다.

1. **시간 복잡도**: O(log n) - 입력 숫자의 자릿수에 비례하는 시간 복잡도를 가지고 있습니다. 숫자의 각 자릿수를 더하는 과정은 숫자의 크기에 따라 반복되며, 숫자의 크기가 줄어들면서 반복 횟수도 줄어듭니다.

2. **공간 복잡도**: O(1) - 입력 숫자와 중간 결과를 저장하기 위한 변수만 사용하므로, 공간 복잡도는 상수입니다.

3. **풀이 접근법**: 이 문제는 수학적 접근법을 사용하여 해결할 수 있습니다. 숫자의 각 자릿수를 더하는 과정을 반복하면, 결국에는 한 자릿수의 숫자로 수렴하게 됩니다. 이 코드에서는 while 루프를 사용하여 이 과정을 구현했습니다.

4. **잘된 점**: 코드는 간결하고, 변수의 이름이 직관적입니다. 또한, 알고리즘의 시간 복잡도와 공간 복잡도가 적절하게 관리되어 있습니다.

5. **개선 사항**: 코드는 이미 충분히 최적화되어 있지만, 더 간단한 수학적 접근법을 사용할 수 있습니다. 예를 들어, 숫자의 각 자릿수를 더하는 과정은 숫자의 디지털 루트(digital root)라고 하는데, 이 값을 계산하는 수학적 공식이 있습니다. 이 공식은 `digital_root = (num - 1) % 9 + 1`으로, 이 코드를 사용하면 while 루프를 완전히 제거할 수 있습니다. 이는 코드를 더 간결하고 효율적으로 만들 수 있습니다.
